# Segmentação de Clientes para Análise de Rentabilidade em Operações de Armazenagem

Código desenvolvido para o Trabalho de Conclusão de Curso.

## Objetivo

Identificar padrões de rentabilidade em operações de armazenagem por meio de:

- Clusterização K-Means
- Correlação de Pearson
- ANOVA
- Análise de Margem de Contribuição
